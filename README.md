# UAV Location Viewer 🚁🗺️



A beginner-friendly graphical desktop application built with Python. It utilizes `tkinter` for the user interface and `tkintermapview` to render an interactive map showing a specific UAV (drone) location upon clicking a button.

#### Features
* **Interactive GUI:** Built with Tkinter window, buttons, and status labels.
* **Map Integration:** Displays an interactive map centered initially on a default region and zooms into the target coordinates upon user interaction.
* **Marker Support:** Drops a custom map marker ("İHA Konumu") at the target location.
